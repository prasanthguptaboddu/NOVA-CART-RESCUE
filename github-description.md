## Short Repository Description
A competition-grade, full-stack operational engine built to rescue NOVA CART's unit economics. Combines real-time dark-store dispatch triage, algorithmic phantom stockout detection, proactive customer SLA rescue credits, and consumption-driven 2nd-order replenishment loops—delivering a 7.7x ROI within a strict ₹25 Lakh budget.

---

## Technology Summary
- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons, Responsive Dark UI
- **Backend**: Express.js REST API co-located with Vite middleware and standalone production server
- **Database**: SQLite 3 via `@libsql/client` with declarative Prisma schema & schema DDL
- **Testing & Verification**: 100% automated test suite (`tests/api.test.ts`), strict TypeScript validation (`tsc --noEmit`), production Vite build

---

## Core Feature Highlights
- **The Churn Chasm Diagnostics**: Visualizes the 4.9x drop in 2nd-order retention caused by 1st-order fulfillment friction.
- **Dark-Store Dispatch & Picker Console**: Real-time order queue with automated in-stock substitute matching and picker cycle tracking.
- **Pre-Checkout Inventory Risk Shield**: Flags shelf-to-app stockout drift and enables one-click cycle audits and SKU quarantine.
- **Preemptive SLA Rescue**: Injects ₹50 Reliance Pass wallet credits for delayed orders before customer complaint or churn.
- **Second-Order Replenishment Loop**: Generates consumption-decay re-stock baskets that apply earned wallet credits at checkout.
- **Executive ROI & Financial Simulator**: Grounded 6-month unit economics model proving 7.7x ROI within the ₹25 Lakh budget constraint.
